# 🔍 Windows Server DFIR Investigation & Log Analysis

## 📌 نظرة عامة (Overview)
يتضمن هذا المستودع تقرير تحقيق جنائي رقمي واستجابة للحوادث (DFIR) لتحليل نشاط اختراق على خادم Windows Server. يوثق التقرير عملية تتبع الأدلة الرقمية، وبناء الخط الزمني للهجوم، وربط التكتيكات المكتشفة بإطار عمل **MITRE ATT&CK**.

## 🛠️ الأدوات والتقنيات المستخدمة (Tools & Methodology)
* **Log Analysis:** تحليل سجلات أحداث ويندوز (Windows Event IDs) وسجلات أوامر PowerShell.
* **Timeline Generation:** استخدام أداة **Hayabusa** وقواعد Sigma لاكتشاف الأنشطة الشاذة وبناء الخط الزمني للاختراق.
* **Threat Mapping:** ربط سلوك المهاجم وتقنيات الاستمرارية والتنفيذ بجدول **MITRE ATT&CK**.
